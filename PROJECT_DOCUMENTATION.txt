# Student Buddy - Complete Project Documentation

## Project Overview
Student Buddy is a comprehensive web application designed to help students manage their academic life efficiently. It combines note-taking, AI-powered assistance, quiz-based learning, collaboration tools, and productivity features in a modern, responsive interface.

### Key Features
- **Note Management**: Rich text editing with AI explain functionality
- **Study Tools**: Course-based quiz generation and practice exams
- **AI-Powered Features**: Note generation, concept explanations, and quiz creation
- **Collaboration**: Sync spaces for group work and shared notes
- **Productivity**: Gamified quiz experience with achievements and streaks
- **Real-time Communication**: WebSocket-based notifications and chat
- **Modern UI/UX**: Dark mode and responsive design

### Technology Stack
**Frontend**: React 18.2.0, React Router DOM 7.6.2, Tailwind CSS 3.3.3, Framer Motion 10.18.0, TipTap Editor, Socket.IO Client 4.8.1, Vite 7.1.7
**Backend**: Node.js, Express.js 4.18.2, MongoDB with Mongoose 8.1.3, Socket.IO 4.7.4, Google Generative AI 0.24.1, JWT authentication
**Development Tools**: npm, ESLint, TypeScript (partial), Vite build tool

## BACKEND COMPONENTS

### Models

#### 1. User Model
**Location**: `backend/models/User.js`
**Purpose**: Defines the user schema with authentication, profile, and preferences
**Key Fields**:
- username, email, password (hashed with bcrypt)
- profile: firstName, lastName, profilePicture, bio
- socialLinks: whatsapp, twitter, instagram, linkedin, github
- level, semesterStart, semesterEnd, freeTime
- notifications: email/push/taskReminders/studyReminders
- preferences: theme, language
- courses: array of course references
- googleAuth: accessToken, refreshToken, expiryDate, connected
**Functions**: Password hashing pre-save hook, password comparison method, virtual profilePictureUrl

#### 2. Note Model
**Location**: `backend/models/Note.js`
**Purpose**: Defines the note schema for storing user notes
**Key Fields**:
- title, content (required)
- subject (optional folder/category)
- course (reference to Course model)
- attachments: array of {name, type, url, size}
- user (reference to User, required)
- createdAt, updatedAt
**Functions**: Basic CRUD operations through controllers

#### 3. Course Model
**Location**: `backend/models/Course.js`
**Purpose**: Defines the course schema for academic course management
**Key Fields**:
- user (reference to User, required)
- name, code (required)
- school, level, semester (required)
- schedule: array of {day, startTime, endTime, location}
- attendance: array of {date, present, note}
- results: array of {assessment, score, maxScore, date}
- createdAt, updatedAt
**Functions**: Timestamps pre-save hook

#### 4. SyncSpace Model
**Location**: `backend/models/SyncSpace.js`
**Purpose**: Defines collaborative workspace schema
**Key Fields**:
- name, joinCode (unique)
- owner (reference to User)
- members: array of user references
- sharedNotes: array of {title, course, originalNoteId, sharedBy, addedBy}
- chat: array of {sender, message, timestamp, isSystemMessage}
- createdAt
**Functions**: Member management, note sharing, real-time chat

#### 5. Notification Model
**Location**: `backend/models/Notification.js`
**Purpose**: Defines notification schema for push notifications
**Key Fields**:
- user (reference to User)
- title, message, type
- read (boolean, default false)
- createdAt
**Functions**: Notification creation and delivery

#### 6. NotificationSubscription Model
**Location**: `backend/models/NotificationSubscription.js`
**Purpose**: Stores web push notification subscriptions
**Key Fields**:
- user (reference to User)
- endpoint, keys (p256dh, auth)
- createdAt
**Functions**: Subscription management for push notifications

#### 7. PracticeExam Model
**Location**: `backend/models/PracticeExam.js`
**Purpose**: Defines practice exam schema
**Key Fields**:
- title, description
- course (reference to Course)
- questions: array of {question, options, correctAnswer, explanation}
- timeLimit (minutes)
- createdBy (reference to User)
- isPublic (boolean)
- createdAt
**Functions**: Exam creation and management

#### 8. AIGeneratedPracticeExam Model
**Location**: `backend/models/AIGeneratedPracticeExam.js`
**Purpose**: Stores AI-generated practice exams
**Key Fields**:
- Similar to PracticeExam but AI-generated
- topic, difficulty, questionCount
- generatedContent
**Functions**: AI exam generation and storage

#### 9. Quiz Model
**Location**: `backend/models/Quiz.js`
**Purpose**: Defines quiz schema for study sessions
**Key Fields**:
- title, description
- course (reference to Course)
- questions: array of quiz questions
- timeLimit
- createdBy
- createdAt
**Functions**: Quiz management

#### 10. StudyNote Model
**Location**: `backend/models/StudyNote.js`
**Purpose**: Specialized note model for study materials
**Key Fields**:
- Similar to Note but with study-specific fields
- tags, difficulty, priority
**Functions**: Study note management

#### 11. Group Model
**Location**: `backend/models/Group.js`
**Purpose**: Defines study group schema
**Key Fields**:
- name, description
- members: array of user references
- createdBy
- createdAt
**Functions**: Group collaboration features

#### 12. CourseTopic Model
**Location**: `backend/models/CourseTopic.js`
**Purpose**: Defines course topic schema
**Key Fields**:
- course (reference to Course)
- title, description, order
- subtopics: array
- createdAt
**Functions**: Course content organization

#### 13. Task Model (Outdated - Task Management Removed)
**Location**: `backend/models/Task.js`
**Purpose**: Legacy task management (no longer used)
**Key Fields**:
- user, title, description, type, priority
- startTime, endTime, repeat
- course, location
- completed, completedAt, missed
- streak tracking fields
- sharedWith, completedBy
**Status**: Outdated, task management system removed from application

### Controllers

#### 1. Note Controller
**Location**: `backend/controllers/noteController.js`
**Purpose**: Handles note CRUD operations and sharing
**Key Functions**:
- `createNote`: Creates new notes with validation
- `shareNoteToSyncSpace`: Shares notes to collaborative spaces with real-time updates
- `importSharedNote`: Imports shared notes into user's collection
**How it works**: Validates input, interacts with Note and SyncSpace models, emits Socket.IO events for real-time updates

#### 2. SyncSpace Controller
**Location**: `backend/controllers/syncSpaceController.js`
**Purpose**: Manages collaborative workspaces
**Key Functions**:
- `createSyncSpace`: Creates new spaces with unique join codes
- `joinSyncSpace`: Adds users to existing spaces
- `getSyncSpaces`: Retrieves user's spaces with population
- `getSyncSpace`: Gets detailed space info with members and content
- `shareTask`: Shares tasks (legacy, may be outdated)
- `completeTask`: Marks shared tasks complete (legacy)
**How it works**: Uses nanoid for join codes, populates related data, handles member management

#### 3. Notification Controller
**Location**: `backend/controllers/notificationController.js`
**Purpose**: Manages push notifications and subscriptions
**Key Functions**:
- `scheduleReminders`: Sets up cron jobs for reminders
- `sendPushNotification`: Delivers web push notifications
- `subscribe`: Stores notification subscriptions
**How it works**: Uses web-push library, integrates with cron scheduling
